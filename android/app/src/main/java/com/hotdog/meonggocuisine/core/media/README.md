# core/media

사진을 올리기 전에 다루는 공용 코드.

| 파일 | 하는 일 |
| --- | --- |
| `UploadPhotoShrinker.kt` | 업로드용 축소 — 긴 변 2,048px 초과·1.5MB 초과·PNG 면 EXIF 방향을 적용해 긴 변 2,048px JPEG(품질 90)로 다시 인코딩한다. 작은 JPEG 는 원본 그대로. 디코딩 실패·메모리 부족이면 원본을 보내 서버 검증에 맡긴다. `UploadPhotoGeometry` 는 줄일지·샘플 배수를 정하는 순수 계산(테스트 대상) |
| `MediaModule.kt` | Hilt 바인딩 |

왜 2,048인가 — 서버 저장 상한은 4,096px 이지만 매칭 모델 입력은 수백 px, 폰 화면도 2,048 이면 충분하다. 4,000px 폰 사진 열 장(25MB)이 6~7MB 로 줄어 느린 회선에서도 타임아웃 없이 올라간다(2026-09-23 QA).
