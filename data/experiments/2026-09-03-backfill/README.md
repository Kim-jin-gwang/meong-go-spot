## 3. 반환 케이스 골든타임 (발견 → 종료 갱신 일수)

반환(`processState`에 "반환" 포함) 195,754건의 `happenDt`(발견일) → `updTm`(마지막 갱신) 일수 분포.

| 일수 | 건수 | 비율 |
|---|---|---|
| 0-3일 | 135,467 | 69.2% |
| 4-7일 | 22,435 | 11.5% |
| 8-14일 | 10,109 | 5.2% |
| 15-30일 | 5,913 | 3.0% |
| 31+일 | 21,830 | 11.2% |

- **반환의 69%가 발견 3일 안에, 81%가 일주일 안에 일어난다.** 주인이 찾으러 오는 창은 짧다 — 입소 당일~다음날 매칭 알림이 가치의 대부분을 만든다는 뜻이며, 일일 배치(22:30)만으로도 1회 이상의 알림 기회가 골든타임 안에 들어온다. 증분(실시간) 경로의 가치는 "그 안에 몇 번 더 기회를 만드는가"로 정의된다.
- 한계: `updTm`은 **최종 갱신 시각**이라 종료 시각과 다를 수 있다(종료 후 재갱신 포함). 따라서 `31+` 11%는 상한이며 실제 장기 반환은 더 적을 수 있다. 정확한 종료일 필드는 API에 없다.

## 4. 이미지 파일 생존 경계 (정찰 단계 실측)

## 5. 이 데이터로 무엇이 바뀌나

- **MapReduce 실데이터 입력 확보**: 쎄타조인(품종·지역·기간 술어)과 자카드 셀프조인(속성 유사)은 임베딩 없이 이 1.63M 레코드로 바로 실측 가능. 합성 벡터 실험(`2026-09-03-scale-kmeans`)과 달리 "진짜 데이터의 분포"에서 나오는 스큐(서울·경기 편중, 믹스견 편중)를 처리하는 부분이 평가 포인트.
- **임베딩·K-Means 색인 대상은 2022~ 구간**(파일이 있는 것만). 2008~2021은 통계·패턴 분석용.
- **제품 근거 수치**: 반환률 12%, 골든타임 3일(69%)·7일(81%) — 기획 문서와 발표의 근거로 인용 가능.
