## 2. 품종 — 공공 코드 테이블을 canonical로 채택

- 상위 3개가 전체의 81.3%: 믹스견 55.2% + 한국 고양이 22.6% + 믹스묘 3.5%. 순종은 롱테일(푸들 2.7%, 말티즈 2.4%, …)
- `kindNm`은 `kindCd`(6자리 코드)와 1:1로 붙어 오는 통제 어휘였다 — 이슈 배경의 "말티즈/몰티즈" 비표준 표기는
  **공공 쪽에는 없고 사용자 자유 입력에서만 생긴다**. 따라서 canonical 코드 = `k`+`kindCd`로 공공 코드 체계를
  그대로 채택하고, 사용자 입력은 label·별칭(음차·축약 변형) 정규화로 흡수한다
- 2024+ 등장 코드 195종 전체를 [vocabulary.json](../../tags/vocabulary.json)에 수록 (코드·표시명·축종·별칭)

## 3. 색 — 자유 텍스트 정규화

원시 고유값 6,098개를 토큰 분석하면 소수 canonical로 수렴한다 (토큰 상위: 흰색 계열 ~12만, 갈색 계열 ~6.5만,
검정 계열 ~5.5만). tags-v1은 **색 8종 + 삼색·무늬 7종(삼색·고등어·줄무늬·턱시도·젖소·호피·얼룩) = 15 코드**로 정의했다.
'옅은'·'바탕에' 같은 수식어는 `ignore_tokens`로 버린다(색 정보 없음 — 매핑 실패로 세지 않음).

(태그 생략 — 어휘 개정 재료로 로그 보존).

## 4. 크기 — 체중 파싱

`weight` 숫자 파싱 성공 99.98%, 여기서 `0(Kg)`(미측정 관례, ~0.2%)을 제외한 **size 태그 생성률 99.8%**. kg 분포로 구간을 정했다: **소형 <8kg 77.2% / 중형 8~20kg 17.8% / 대형 ≥20kg 5.0%**
(고양이·강아지가 소형에 몰리는 것은 자연스러움 — 축종 태그가 별도로 있어 변별은 조합으로 성립).
**단, 사용자 게시물에는 크기·체중 입력 필드가 없다**(ERD `animal_case`) — 필드 신설(선택 입력, 모름 허용)이 팀 합의 안건이며,
신설 전까지 size는 공공 건만 갖는 비대칭 태그라 자카드 생성기에서 제외하거나 양측 보유 시에만 쓴다.

## 5. "모름" 결측 영향과 사진 추론 보완 필요성 판단

- 공공(갤러리 측): 결측 0% — 자카드 한쪽 축은 항상 태그가 있다
- 사용자(질의 측): `모름` 허용 필드는 품종·색(·신설 시 크기). 모름이면 태그 생략 → 집합이 작아지고,
  전부 모름이면 빈 집합 → 자카드 0. **매칭의 주 경로는 이미지 임베딩(kNN)이고 자카드는 보조 신호이므로
  태그 부재가 매칭 실패로 이어지지 않는다**
- **판단: 사진 기반 zero-shot 추론 보완은 지금 불필요.** 근거: ① 공공 쪽 결측이 0%라 보완의 대상은 사용자 입력뿐,
  ② 사용자 결측률은 서비스 오픈 전이라 실측 불가, ③ CLIP 계열 보류는 팀 결정. **후속 이슈 제안**: 오픈 후
  사용자 게시물의 속성별 `모름` 비율을 측정하고, 색·품종 모두 모름 비율이 유의하면(예: >30%) 그때 zero-shot
  보완을 재검토한다 — 이번 이슈에서는 구현하지 않음
