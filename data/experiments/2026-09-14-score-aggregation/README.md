# 동물 점수 집계 규칙과 임계값 실험 (2026-09-14, #143)

계약 `docs/data-ai-interface.md` §후보 출력 정책 0-2 는 "질의 사진이 여러 장이면 동물 점수는 쌍 코사인의
최댓값" 을 **잠정**으로 두고, 최댓값·상위 2개 평균·폴백 가중 중 무엇을 쓸지와 "유사하다" 의 점수 임계값을
임계값 곡선과 함께 확정하기로 했다. 이 실험이 그 둘을 같은 정답쌍 집합에서 잰 기록이다.

도구: `data/eval/eval_aggregation.py`. 산출: `aggregation.json`(전국 갤러리), `aggregation-pool100.json`,
`aggregation-pool400.json`(같은 축종 후보 풀).

## 설정

| 항목 | 값 |
|---|---|
| 갤러리 | 스냅샷 2026-09-13 — 456,335장 / **253,748 개체**, 폴백 55,232장(12.1%), `fallback.npy` 포함 |
| 정답쌍 | `pairs-v2.tsv` 같은 개체의 사진 1→사진 2, 중복 사진 제외 **113,493쌍** (전국 갤러리는 1,500 표본, seed 42) |
| 질의 | 사진 1 + 무관 사진 m 장 (m=0·1·2·4 → 1·2·3·5장). 무관 사진은 갤러리에서 무작위, **그 사진과 그 개체는 갤러리에서 뺀다** |
| 후보 단위 | **개체** (사진 ≤ 2장). rank = 1 + \|{ a : score(a) > score(정답) }\| |
| 후보 풀 | ① 전국 25만 개체 ② 질의와 같은 축종 개체 100마리 + 정답 ③ 같은 축종 400마리 + 정답 — 제품은 보호중·지역·축종·실종일로 후보를 수십~수백 마리로 좁힌다(2026-09-09 실측 64~166) |
| 규칙 | `max` · `top2_mean`(쌍 점수 상위 2개 평균) · `mean_max`(질의 사진별 최고점의 평균) · `fb_max`/`fb_mean_max`(탐지 성공 사진이 있으면 폴백 질의 사진 제외) · `max_gw`/`fb_max_gw`(갤러리 폴백 사진 쌍 점수 ×0.8) |
| 실행 | 서버 2, 전국 갤러리 4시나리오 1,500쌍 48분 / 풀 100 전량 3시나리오 4분 / 풀 400 전량 16분 |

recall@5 / @20 (풀 100): `max` 1장 0.887/0.936 · 2장 0.862/0.923 · 3장 0.841/0.912. 전국 1장 `max` 0.514 는 -108 평가(0.517)와 일치한다.

**읽기**

- **`max` 가 유일하게 혼입을 견딘다.** 무관 사진 한 장이 섞이면 평균 계열은 무너진다 — `top2_mean` 은 0.0 (무관 사진의 최고 매치 둘이 평균을 차지), `mean_max` 는 진짜 사진이 소수가 되는 순간 무관 사진 쪽 평균에 끌려간다. 깨끗한 1장에서 `top2_mean` 이 1.5~3.7pt 앞서지만, 그 이득을 위해 혼입 붕괴를 감수할 수 없다.
- **폴백 질의 사진 제외(`fb_*`)는 도움이 안 된다.** 전국에서 −0.8~+0.2pt(표본 오차 ±1.3pt 안), 풀 100 에서 **−5.8pt**(0.764→0.706), 풀 400 에서 −4.9pt. 진짜 사진이 폴백(12%)이면 제외 규칙이 유일한 신호를 버린다 — 정답 점수 p10 이 0.486 → 0.236 으로 떨어지는 것이 그 자국이다. 계약 0-2 의 "탐지 성공 사진이 있으면 폴백 질의 사진은 뺀다" 는 **철회**한다.
- **갤러리 폴백 가중 0.8 도 손해**(전국 1장 −2.0pt). 정답 사진이 폴백인 경우를 같이 깎는다.
- `max` 의 알려진 약점은 실재한다: 무관 사진 한 장당 recall@1 이 5~10pt 씩 내려간다(전국 0.514→0.415→0.361, 풀 100 0.806→0.764→0.733). 이것은 규칙으로 못 막고, 사용자가 자기 동물 사진만 올리게 하는 UX 와 Top-20 목록(recall@20 은 3장에서도 0.91)이 흡수한다.
- 후보 풀이 작을수록 모든 수치가 좋다(전국 0.51 → 400마리 0.75 → 100마리 0.81). **계약 0 의 사전 필터가 벡터 검색보다 먼저 품질을 결정한다.**

## 결과 2 — 임계값 곡선 (`max`, 질의 1장)

recall(τ) = 정답 개체 점수 ≥ τ 인 비율(풀과 무관). false_alarm(τ) = 정답을 뺀 최고 사칭자 점수 ≥ τ 인 비율 — 실종 동물이
보호소에 **없을 때** 엉뚱한 후보를 보여줄 확률의 근사. shown = τ 이상 개체 수 평균(K=20 상한 전).

| τ | recall | 전국 false_alarm | 풀400 false_alarm / shown | 풀100 false_alarm / shown |
|---|---|---|---|---|
| 0.50 | 0.892 | 1.000 | 0.942 / 38.0 | 0.839 / 10.2 |
| 0.55 | 0.865 | 0.997 | 0.881 / 24.4 | 0.737 / 6.8 |
| **0.60** | **0.828** | 0.992 | 0.781 / 14.6 | **0.605 / 4.3** |
| 0.65 | 0.781 | 0.963 | 0.634 / 8.0 | 0.451 / 2.6 |
| 0.70 | 0.720 | 0.901 | 0.455 / 3.8 | 0.288 / 1.5 |
| 0.75 | 0.633 | 0.774 | 0.264 / 1.6 | 0.139 / 0.9 |
| 0.80 | 0.520 | 0.532 | 0.097 / 0.7 | 0.037 / 0.6 |
| 0.85 | 0.373 | 0.226 | 0.012 / 0.4 | 0.004 / 0.4 |

질의 3장(무관 2장)이면 사칭자 점수가 올라 풀 100 의 false_alarm 은 0.60 에서 0.824, shown 6.9 다(`aggregation-pool100.json`).

정답 점수 분포: 중앙값 0.808, p10 0.484, p90 0.935. 최고 사칭자 중앙값: 전국 0.806 / 풀 400 0.688 / 풀 100 0.635.
**전국 갤러리에서는 두 분포가 겹쳐 어떤 τ 도 못 고른다** — 25만 개체 중 최댓값은 늘 높다. 임계값은 사전 필터 뒤의
후보 크기를 전제로만 의미가 있다.

## 결정

1. **집계 규칙 = `max`** (쌍 코사인 최댓값). 평균 벡터·평균 점수·상위 2개 평균·폴백 제외·폴백 가중 모두 채택하지 않는다.
2. **점수 임계값 τ = 0.60** (`dinov2_vitb14` v2). 근거:
   - 목록은 K=20 으로 잘리고 사용자가 사진을 보고 판단하므로, 되돌릴 수 없는 오류는 **진짜 짝을 안 보여주는 것**이다. 0.60 은 정답의 83% 를 살린다(0.65 는 78%, 0.70 은 72%).
   - 후보 100마리 조건에서 τ 이상 개체는 평균 4.3마리(98% 가 20 이하) — 목록이 넘치지 않는다. 400마리면 14.6마리(75% 가 20 이하)라 상한에 걸리기 시작한다.
   - 보호소에 없는 동물의 사용자에게 엉뚱한 후보가 보일 확률은 60%(풀 100)다. 이것은 "없어요" 판정의 한계이고, 후보 화면이 "유사할 수 있는 동물" 임을 문구로 분명히 해야 한다(제품 몫).
   - 2026-09-09 시연과 맞는다: 보호중 이탈리안 그레이하운드 짝 0.670 은 통과, 반환된 포메의 후보 전부 ≤0.56 은 "없어요".
3. 임계값은 **모델 버전별 엔진 설정**으로 둔다(-144). 모델이 바뀌면 이 실험을 그 벡터로 다시 돌려 값을 갱신한다 — 곡선은 모델 고유다.
4. 정답의 17% 가 0.60 아래다(p10 0.484). 이들은 순위로는 Top-20 안(recall@20 0.936)이지만 임계값이 가린다. 실사용에서 "없어요" 가 잦다는 피드백이 오면 0.55 로 낮추는 것이 첫 조정이다 — 그때 shown 은 6.8 이다.

## 한계

- 공공 데이터는 개체당 사진이 2장이라 **같은 개체 사진 3~10장** 질의는 만들 수 없다. 이 실험은 무관 사진 혼입 강건성만 잰다. 사용자 사진이 전부 같은 동물이면 규칙 간 차이는 작고, `max` 가 가장 좋은 각도 한 장으로 점수를 내므로 불리하지 않다.
- 정답쌍은 같은 보호소가 같은 날 찍은 두 장이라 실제 시나리오(사용자 촬영 vs 보호소 촬영, 시간차)보다 쉽다. 절대값은 낙관적일 수 있고, 규칙·임계값의 **상대 비교**로 읽는다.
- 후보 풀은 같은 축종의 무작위 개체다. 제품 필터(지역·날짜)가 만드는 풀은 비슷한 품종이 몰릴 수 있어 사칭자 점수가 더 높을 수 있다.
- 사칭자 p99 가 0.83~0.90 이다 — 어떤 τ 를 써도 1% 의 질의에서는 매우 닮은 남의 개가 목록 상단에 온다. 사진으로 판단하는 것은 결국 사용자다.
